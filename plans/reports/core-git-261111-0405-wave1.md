# Wave 1: MercuryCore + MercuryGit

Status: done. Both `swift test --package-path Packages/MercuryCore` (9 tests) and
`swift test --package-path Packages/MercuryGit` (31 tests, 4 suites) pass; no warnings in package sources
under Swift 6 language mode.

## MercuryCore
- `Store.swift`: `MercuryStore` (final class, Sendable) over a GRDB `DatabaseQueue`, foreign keys on. All
  contract methods; `save` upserts; `setSetting(key, nil)` deletes. Ordering: workspaces by
  `sortOrder, createdAt`; worktrees, sessions, accounts by `createdAt`.
- `Migrations.swift`: migration `v1` with `workspace` (with `kind`), `worktree`, `agent_session`,
  `managed_account`, `setting(key, value)`. UUIDs are 16-byte blobs (GRDB native), dates are REAL seconds
  since 2001 (exact round trip).
- FKs: worktree.workspaceID and agent_session.workspaceID cascade; agent_session.worktreeID cascades
  (removing a worktree removes its sessions); agent_session.accountID is SET NULL (deleting an account keeps
  session history). The last two are choices beyond the contract.
- `Records.swift`: GRDB conformances in a separate file; `Models.swift` untouched.

## MercuryGit
- `GitRunner.swift`: `GitRunner`, `GitError`, `GitResult`, `GitRepository.toplevel`. Process runs on a GCD
  thread, stdout/stderr drained concurrently (tested with ~2 MB output). Env adds `LC_ALL=C`,
  `GIT_TERMINAL_PROMPT=0`, `GIT_OPTIONAL_LOCKS=0`, `GIT_PAGER=cat`; stdin is /dev/null.
  Extra overload `run(_:in:allowedExitCodes:) -> GitResult` for commands like `diff --no-index` (exit 1).
- `Worktree.swift` / `Branch.swift`: `Worktree`, `WorktreeService` (list via `--porcelain -z`, add, remove,
  prune, hasUncommittedChanges, defaultPath, localBranches, currentBranch, defaultBaseBranch).
- `DiffModels.swift`, `DiffParser.swift`, `DiffService.swift`. Parser handles new/deleted files, renames and
  copies with similarity, binary, `\ No newline at end of file`, multiple hunks, quoted (C-escaped/UTF-8)
  and space-containing paths, CRLF content, mode-only changes; hunk bodies are bounded by header counts, so
  content lines like `--- x` are not misread as headers.
- DiffService: `.againstBase(b)` = `git diff <merge-base b HEAD>` (committed + working tree) plus untracked;
  `.uncommitted` = `git diff HEAD` (empty tree before the first commit) plus untracked. Per-file diff passes
  both paths for renames, uses `diff --no-index -- /dev/null <file>` for untracked files, and forces
  `--src-prefix=a/ --dst-prefix=b/ --no-ext-diff --no-color` to ignore user diff config.

## Contract notes (additive only, no renames)
- `FileChangeKind`, `DiffLineKind`, `DiffScope` also conform to `Hashable` (needed because `ChangedFile` and
  `DiffLine` are Hashable).
- `FileDiff` has an extra `similarity: Int?` (default nil) and `displayPath`.
- `GitError` also conforms to `Sendable`.
- `DiffService` assumes `worktree` is the checkout root (paths are toplevel-relative).

## Review fixes (L5, L6)
- L5: `GitRunner.environment(inheriting:)` drops every inherited `GIT_*` variable except transport settings
  (`GIT_SSH`, `GIT_SSH_COMMAND`, `GIT_SSH_VARIANT`, `GIT_ASKPASS`, `GIT_SSL_CAINFO`, `GIT_SSL_CAPATH`), then
  sets its own. This removes `GIT_DIR`, `GIT_WORK_TREE`, `GIT_INDEX_FILE`, `GIT_COMMON_DIR`,
  `GIT_OBJECT_DIRECTORY`, `GIT_CEILING_DIRECTORIES`, `GIT_CONFIG_*`, `GIT_NAMESPACE` and the rest.
- L6: new `WorktreeService.validateBranchName(_:) async -> Bool` uses `git check-ref-format --branch`. It also
  rejects a leading `-`, `HEAD`, `@` (git accepts `@` as a branch name, but `@` means HEAD in revisions) and
  shorthands git expands (`@{-1}`). `add` validates the branch and throws `GitError` for an invalid one.
  `--end-of-options` now comes before revision and path arguments in `worktree add`, `worktree remove`,
  `merge-base` and both `diff` calls.
- Tests: new `ArgumentSafetyTests` (4 tests). Without the fix, `--no-checkout` as a base and `--fork-point` as
  a diff base both succeeded as flags; the tests failed then and pass now. MercuryGit: 35 tests in 5 suites
  pass, no warnings.
- There is no end-to-end test with a real inherited `GIT_DIR`: `setenv` would race with parallel tests in
  the same process. The pure `environment(inheriting:)` function is tested instead.
