# Changelog

## 0.1.0 (unreleased)

- Settings › Shortcuts lists every keyboard shortcut and mouse gesture, searchable by action or key. Help ›
  Keyboard Shortcuts (⌘/) opens it.

  new name; see `docs/architecture.md`, "Moving an install from the old name".
